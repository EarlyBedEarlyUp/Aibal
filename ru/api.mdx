Клиенты и модели для мультимедиа используют разные протоколы и пути. Откройте нужное руководство и используйте адрес, модель и формат запроса, подходящие группе вашего ключа.

## Выберите способ подключения

<Card title="Обзор подключения" href="/ru/integrations">

</Card>

<Card title="API изображений" href="/ru/text-to-image">
  Примеры генерации, редактирования и сохранения результатов из Base64 или по URL.
</Card>

<Card title="API видео" href="/ru/text-to-video">
  Примеры создания задач Seedance, проверки статуса и скачивания видео.
</Card>

<Note>
Создайте и включите API-ключ, затем проверьте доступ к модели и лимит. Храните ключ в переменной окружения или надёжном менеджере секретов. Не добавляйте его в публичный браузерный код и не переносите путь одного API в другой.
</Note>
