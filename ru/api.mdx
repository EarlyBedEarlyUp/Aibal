## Базовый URL

```text
https://aibal.ai/v1
```

Передавайте ключ проекта в заголовке:

```http
Authorization: Bearer YOUR_API_KEY
```

## Chat Completions

```bash
curl https://aibal.ai/v1/chat/completions \
  -H "Authorization: Bearer $AIBAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"your-model-id","messages":[{"role":"user","content":"Summarize this text."}]}'
```

Ответ использует привычную структуру `choices`, `message` и `usage`. Поле `usage` помогает оценивать токены и расходы.

## Выбор модели

Значение `model` указано в панели. Доступность, контекст, цена и возможности зависят от рабочего пространства; актуальные данные смотрите в панели.

## Потоковая выдача

Для потоковой выдачи добавьте `"stream": true` и обрабатывайте события server-sent events по мере поступления. Обычные запросы проще журналировать и повторять.

## Практические рекомендации

- Установите тайм-аут и повторяйте только безопасные временные ошибки.
- Записывайте ID запроса и задержку, удаляя секретные данные из журналов.
- Используйте отдельный ключ для каждого сервиса.
- Проверяйте ввод и ограничивайте длину ответа.

## Группы и бюджеты

Разделяйте продукты, окружения или клиентов с помощью групп рабочего пространства. Назначайте ключи нужной группе и регулярно проверяйте использование.
