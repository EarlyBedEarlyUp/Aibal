Это руководство посвящено Claude Code CLI. Вы настроите адрес сервиса, API-ключ и доступную модель Claude, а затем проверите первый диалог в терминале.

## Перед началом

- [Создайте API-ключ](/ru/create-api-key) в группе с поддержкой Claude Code. Проверьте доступные модели Claude и баланс.
- Подготовьте папку проекта. Для первой проверки подойдёт пустая папка.
- Проверьте [официальные системные требования Claude Code](https://code.claude.com/docs/en/setup).

## Настройка Claude Code

<Steps>
  <Step title="Установите Claude Code">
    В терминале macOS, Linux или WSL выполните официальную команду установки:

    ```bash
    curl -fsSL https://claude.ai/install.sh | bash
    ```

    В Windows PowerShell:

    ```powershell
    irm https://claude.ai/install.ps1 | iex
    ```

    Затем выполните `claude --version`. Если команда не найдена, откройте терминал заново и проверьте `PATH` по подсказкам установщика.
  </Step>
  <Step title="Проверьте настройки для ключа">
    Войдите на [aibal.ai](https://aibal.ai/), в списке API-ключей откройте **Использовать ключ**, выберите Claude Code и свою операционную систему. Проверьте адрес и полный идентификатор поддерживаемой модели Claude. Замените `YOUR_AVAILABLE_CLAUDE_MODEL_ID` в примерах ниже.
  </Step>
  <Step title="Укажите адрес, ключ и модель">
    В Bash или Zsh выполните команды и вставьте ключ по запросу скрытого ввода:

    ```bash
    export ANTHROPIC_BASE_URL="https://aibal.ai"
    export ANTHROPIC_AUTH_TOKEN="$(bash -c 'read -r -s -p "aibal.ai API Key: " key; printf "\n" >&2; printf "%s" "$key"')"
    export ANTHROPIC_MODEL="YOUR_AVAILABLE_CLAUDE_MODEL_ID"
    ```

    В Windows PowerShell:

    ```powershell
    $env:ANTHROPIC_BASE_URL = "https://aibal.ai"
    $credential = Get-Credential -UserName "aibal" -Message "Paste your aibal.ai API Key in the password field"
    $env:ANTHROPIC_AUTH_TOKEN = $credential.GetNetworkCredential().Password
    Remove-Variable credential
    $env:ANTHROPIC_MODEL = "YOUR_AVAILABLE_CLAUDE_MODEL_ID"
    ```

    Не добавляйте `/v1/messages` к базовому адресу. Если **Использовать ключ** показывает отдельный путь для группы, сохраните указанный там полный базовый адрес.
  </Step>
  <Step title="Запустите клиент и проверьте подключение">
    В том же терминале перейдите в папку проекта и выполните `claude`. Завершите начальную настройку, затем введите `/status`. Убедитесь, что **Anthropic base URL** указывает на aibal.ai, а источник учётных данных — `ANTHROPIC_AUTH_TOKEN`.
  </Step>
  <Step title="Отправьте первое сообщение">
    Введите:

    ```text
    Ответь только «Подключение успешно». Не читай и не изменяй файлы, не выполняй команды.
    ```

    Получив ответ, проверьте модель, время и стоимость в **Истории использования** aibal.ai. Проверочный запрос может быть платным; до начала работы уточните баланс и лимит ключа.
  </Step>
</Steps>

## Назначение трёх переменных

| Переменная | Назначение |
| --- | --- |
| `ANTHROPIC_BASE_URL` | Базовый адрес шлюза, обычно `https://aibal.ai` |
| `ANTHROPIC_AUTH_TOKEN` | API-ключ aibal.ai, передаваемый как Bearer token |
| `ANTHROPIC_MODEL` | Полный идентификатор модели Claude, доступной выбранной группе |

Эти временные переменные действуют в текущем терминале. В новом терминале задайте их повторно. Для сохранения и переключения настроек через графический интерфейс используйте [cc-switch](/ru/cc-switch). Не помещайте настоящий ключ в настройки проекта, которые попадут в Git.

## Частые вопросы

### Клиент по-прежнему предлагает войти в прежний аккаунт

Проверьте адрес и источник учётных данных через `/status`. Одного адреса без ключа недостаточно. Проверьте, не конфликтуют ли `ANTHROPIC_API_KEY`, `apiKeyHelper` или значения в файлах настроек. Оставьте нужный источник и перезапустите клиент.

### Переменные не действуют в VS Code или приложении для компьютера

Переменные терминала передаются только запущенным из него дочерним процессам. Это руководство относится к CLI. У расширения VS Code и приложения для компьютера свои настройки; используйте [официальную инструкцию подключения к шлюзу](https://code.claude.com/docs/en/llm-gateway-connect).

### Основная модель работает, а другая модель или подзадача — нет

Разным моделям могут требоваться разные права группы. Не считайте стандартные псевдонимы Sonnet, Opus и Haiku автоматически доступными. Используйте точные идентификаторы из консоли; при необходимости сопоставления моделей следуйте разделу **Использовать ключ**.

### Ошибка 401, 404, 429 или недостаточно квоты

Проверьте соответственно ключ, лишний `/v1` в адресе, ограничения параллельных запросов и частоты, а также баланс или квоту ключа. Не повторяйте многократно задачи, которые могут оплачиваться. Подробнее — в [обзоре интеграций](/ru/integrations).

## Безопасность ключей и дальнейшие действия

Не отправляйте модели настоящие ключи и не делитесь скриншотами терминала или настроек с ключами. При утечке отключите старый ключ в консоли, создайте новый и обновите настройки.

После подключения поручите Claude Code небольшую понятную задачу, например объяснить файл. Перед изменениями убедитесь, что у проекта есть резервная копия или система контроля версий.

Источники: [официальная установка](https://code.claude.com/docs/en/setup), [официальное подключение к шлюзу](https://code.claude.com/docs/en/llm-gateway-connect).
