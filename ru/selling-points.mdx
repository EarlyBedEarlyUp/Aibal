aibal.ai помогает сократить повторную настройку, чтобы вы могли сосредоточиться на творчестве и разработке. Проверьте результат в браузере, при необходимости подключите инструмент или приложение и отслеживайте использование в той же консоли.

## Управление в одном аккаунте

Пополняйте баланс, создавайте API-ключи, просматривайте историю использования и доступные права в одном месте. При смене задачи не нужно осваивать новый интерфейс управления аккаунтом.

Например, заведите отдельные ключи для программирования, создания изображений и тестовых скриптов, а затем проверяйте соответствующие записи об использовании.

## От браузера к API

Начните с [генерации изображений](/ru/text-to-image) или [видео](/ru/text-to-video). Для повторяющихся задач и интеграции в свой продукт используйте примеры API из этих руководств.

И в браузере, и через API действуют требования группы, баланса и лимитов. Пробный запуск в браузере не означает бесплатный запрос.

## Подключение привычных инструментов

Доступны инструкции для [cc-switch](/ru/cc-switch), [Codex](/ru/codex) и [Claude Code](/ru/claude-code). Выберите визуальное управление настройками или редактирование конфигурации клиента.

Разные инструменты используют разные протоколы и форматы адресов. В каждом руководстве указан нужный адрес, включая необходимость добавления `/v1`.

## Проверка использования и расходов

На **Панели управления** смотрите сводку, а в **Истории использования** — доступные сведения о моделях, токенах и стоимости. Начните с небольшой задачи, оцените результат и фактические расходы, затем планируйте дальнейшее использование.

Расчёт стоимости изображений и видео может отличаться от текстовых моделей. Проверяйте актуальные цены, коэффициенты и условия: единая цена или скидка не обязательно действует для всех моделей.

## Отдельные ключи для разных задач

Создайте API-ключ для каждого проекта и задайте лимит и срок действия. При необходимости добавьте ограничения IP или частоты запросов, чтобы уменьшить последствия неправильного использования.

Лимит ключа ограничивает расходы по нему, но не пополняет баланс аккаунта. Замена ключа не отменяет ограничения группы или аккаунта.

## Для каких сценариев подходит

| Сценарий | Рекомендуемый подход |
| --- | --- |
| Обучение и личное творчество | Начните с [пробы в браузере](/ru/web-quickstart), чтобы оценить результат и стоимость |
| Повседневное программирование с ИИ | Выберите [инструкцию по интеграции](/ru/integrations) и отдельный ключ для программирования |
| Скрипты и автоматизация | Используйте нужный API, сохраняйте идентификаторы запросов или задач и не повторяйте запрос вслепую при неизвестном результате |
| Несколько проектов | Разделяйте ключи по проектам или окружениям, задавайте лимиты и сроки; не передавайте всем пароль основного аккаунта |

## Что проверить перед началом

1. **Возможности**: нужная модель и функция доступны в выбранной группе.
2. **Стоимость**: баланс, лимит ключа, цена и срок действия подходят для задачи.
3. **Результат**: небольшой запрос позволяет проверить качество и совместимость инструмента.
