Работайте с aibal.ai в браузере или подключите API к локальному инструменту для программирования. Сначала выберите инструмент, затем следуйте его руководству.

## Выберите способ подключения

| Ваша задача | Рекомендуемое руководство | Что потребуется |
| --- | --- | --- |
| Попробовать генерацию изображений или видео без установки программ | [Быстрый старт в браузере](/ru/web-quickstart) | Вход в аккаунт, API Key и доступный баланс |
| Управлять провайдерами инструментов через графический интерфейс | [cc-switch](/ru/cc-switch) | CC Switch, нужный клиент и API Key |
| Использовать Codex в терминале | [Codex](/ru/codex) | Codex CLI, модель с поддержкой Responses и API Key |
| Использовать Claude Code в терминале | [Claude Code](/ru/claude-code) | Claude Code, доступная модель Claude и API Key |
| Генерировать изображения или видео из своей программы | [Изображения по тексту](/ru/text-to-image) / [Видео по тексту](/ru/text-to-video) | Среда выполнения и доступ к нужному сервису |

## Подготовка

<Steps>
  <Step title="Подготовьте аккаунт">
    [Зарегистрируйтесь](/ru/register), войдите на [aibal.ai](https://aibal.ai/) и убедитесь, что аккаунт доступен. При необходимости воспользуйтесь [руководством по пополнению](/ru/recharge).
  </Step>
  <Step title="Создайте ключ для инструмента">
    [Создайте API Key](/ru/create-api-key). Используйте отдельные названия, например `codex-laptop` и `claude-work`. Убедитесь, что ключ включён, срок его действия не истёк, а его группа поддерживает нужную модель.
  </Step>
  <Step title="Посмотрите настройки подключения для ключа">
    В списке ключей нажмите **Использовать ключ**, выберите клиент и операционную систему. Ориентируйтесь на адреса и настройки моделей из этого окна: они могут различаться для разных групп. Пароль аккаунта не заменяет API Key.
  </Step>
  <Step title="Настройте и проверьте подключение">
    Следуйте руководству для выбранного инструмента, сохраните настройки и начните новый сеанс. Отправьте короткое сообщение, затем проверьте модель и расход в разделе **История использования**, прежде чем переходить к большой задаче.
  </Step>
</Steps>

<Note>
Тестовые сообщения обращаются к модели и могут тарифицироваться. Доступные модели, цены и лимиты определяются текущими данными панели. Возможность создавать изображения в браузере не означает, что ключ автоматически получает доступ ко всем текстовым моделям и моделям видео.
</Note>

## Адреса, ключи и идентификаторы моделей

| Поле | Значение | Частая ошибка |
| --- | --- | --- |
| Base URL для Codex / OpenAI-совместимого клиента | `https://aibal.ai/v1` | Адрес страницы входа или повторное добавление `/v1` |
| `ANTHROPIC_BASE_URL` для Claude Code | `https://aibal.ai` | Добавление `/v1/messages`: клиент сам формирует путь запроса |
| API Key | Ключ вашего аккаунта с доступом к нужной группе | Пароль, код подтверждения или ключ другого провайдера |
| Модель | Полный ID модели, поддерживаемой конфигурацией ключа | Отображаемое название или ID модели другого провайдера |
| Протокол | `responses` для Codex; Anthropic-совместимые настройки для Claude Code | Замена имени модели без проверки совместимости API |

Это стандартные адреса. Если окно **Использовать ключ** показывает специальный адрес группы с дополнительным путём, сохраните адрес полностью и используйте конфигурацию этой группы.

## Как проверить успешное подключение

Обычный ответ клиента и соответствующая запись с временем, ключом и моделью в разделе **История использования** подтверждают, что запрос прошёл через ваш аккаунт aibal.ai. Сохранение настроек или запуск клиента сами по себе не подтверждают успешный вызов модели.

## Частые вопросы

### Ошибка 401 или недействительный ключ

Скопируйте ключ целиком ещё раз. Проверьте лишние пробелы, действие переменной окружения в текущем терминале и статус ключа: он мог быть удалён или отключён. Не публикуйте ключ в чате или обращении в поддержку.

### Модель недоступна или доступ запрещён

Проверьте группу ключа, полный ID модели и протокол клиента. Используйте модель из инструкции для этого ключа. Если ошибка остаётся, передайте поддержке текст ошибки, время и версию клиента.

### Ошибка 404, 429 или недостаточный баланс

При `404` проверьте, не повторяется ли `/v1`. При `429` проверьте ограничения частоты и одновременных запросов, затем снизьте частоту обращений. При ошибках баланса или квоты проверьте баланс аккаунта, состояние подписки и лимит ключа, затем следуйте сообщению об ошибке.

### Что отправить в поддержку?

Укажите название и версию клиента, время, ID модели, Base URL без секретов и текст ошибки. На снимках скройте ключи, адреса электронной почты и данные аккаунта. Если ключ раскрыт, сразу отключите его и создайте новый.
