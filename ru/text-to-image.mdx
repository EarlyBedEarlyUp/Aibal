Опишите изображение в браузере или вызовите генерацию из своего приложения. Чтобы изменить существующее изображение, добавьте референсы.

## Перед началом

- Войдите в [aibal.ai](https://aibal.ai/login) и подготовьте активный [API-ключ](/ru/create-api-key) с доступом к генерации изображений.
- Проверьте баланс аккаунта и лимит ключа; при необходимости [пополните баланс](/ru/recharge). Генерация в браузере тоже оплачивается.
- Загружайте только материалы, которые вы вправе обрабатывать. Не используйте изображения паролей, документов и других конфиденциальных данных.

Доступные модели, параметры и цены определяются текущими условиями в панели управления. В примерах используется модель онлайн-студии `gpt-image-2`.

## Генерация в браузере

<Steps>
  <Step title="Откройте генерацию изображений">
    Откройте [генерацию изображений](https://aibal.ai/image-studio) и выберите **API-ключ** в области параметров. Если активного ключа нет, нажмите **Управление API-ключами**, создайте или включите ключ и вернитесь.
  </Step>
  <Step title="Выберите параметры">
    Для первой попытки оставьте **Пропорции и размер: Авто**, **Качество: Авто**, **Количество: 1**, **Формат: PNG**. Серые варианты размера недоступны; наличие варианта на странице не означает, что его можно использовать.
  </Step>
  <Step title="Опишите изображение">
    В поле **Промпт** укажите объект, сцену, композицию и стиль. Например: «Рыжий котёнок у солнечного окна, мягкий дневной свет, размытые зелёные растения на фоне, акварельная иллюстрация, без текста».

    Для генерации из текста референс не нужен.
  </Step>
  <Step title="Отправьте запрос">
    Нажмите **Создать** и дождитесь смены статусов **Отправка** и **Обработка** на **Готово**. Держите страницу открытой. При обрыве соединения сначала проверьте историю использования.
  </Step>
  <Step title="Просмотрите и сохраните">
    Нажмите **Просмотр** на карточке результата, затем **Скачать**. Для дальнейших изменений используйте **Копировать промпт** или **Повторить параметры**.
  </Step>
</Steps>

<Warning>
Список результатов генерации изображений хранится в текущем сеансе страницы. Скачайте нужные файлы перед обновлением или выходом. Закрытие страницы не означает отмену генерации у поставщика.
</Warning>

### Выбор параметров

| Поле | Как использовать |
| --- | --- |
| **Модель** | Сейчас на странице указана `gpt-image-2`; группа ключа должна разрешать эту модель. |
| **Пропорции и размер** | Используйте **Авто**. Доступны только активные варианты; серые фиксированные размеры выбрать нельзя. |
| **Качество** | Авто, низкое, среднее или высокое. Начните с авто и оцените результат. |
| **Количество** | От 1 до 4 изображений. Начните с одного; увеличение количества может повысить стоимость. |
| **Формат** | PNG, JPEG или WebP — в зависимости от назначения файла. |
| **Сжатие** | Только для JPEG / WebP. Меньшее значение означает более сильное сжатие; для PNG параметр не применяется. |
| **Фон** | Авто или непрозрачный. Авто не гарантирует прозрачный фон. |

### Редактирование по референсам

Нажмите **Добавить референсы (необязательно)** и загрузите PNG, JPEG или WebP. Допускается до 4 файлов, до 10 МБ каждый и до 40 МБ суммарно. При нескольких изображениях можно выбрать **Сделать главным**; для ненужного файла нажмите **Удалить**.

Опишите изменение, например: «Сохрани объект и композицию, замени фон на светло-голубой». Нажмите **Создать**, затем просмотрите и скачайте результат. Готовое изображение также можно выбрать действием **Как референс**.

## Генерация через API

Установите `curl` и безопасно задайте переменную окружения `AIBAL_API_KEY` на своём устройстве. Не записывайте настоящий ключ в документацию, общие скрипты или репозиторий. Эти команды отправляют реальные запросы и могут привести к списаниям.

### Запрос генерации из текста

```bash
curl --fail-with-body https://aibal.ai/v1/images/generations \
  -H "Authorization: Bearer $AIBAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "An orange kitten by a sunny window, watercolor illustration, no text",
    "n": 1,
    "output_format": "png",
    "background": "auto"
  }' \
  -o image-response.json
```

Отсутствие `size` и `quality` соответствует автоматическим настройкам веб-страницы. При успехе массив `data` содержит изображения в виде `b64_json` или `url`; не каждый ответ содержит готовую ссылку.

Если есть `data[0].b64_json`, сохраните первый PNG с помощью Python 3:

```bash
python3 -c 'import base64,json,pathlib; r=json.loads(pathlib.Path("image-response.json").read_text()); pathlib.Path("image.png").write_bytes(base64.b64decode(r["data"][0]["b64_json"]))'
```

Если возвращён `data[0].url`, откройте ссылку и скачайте результат. Не передавайте API-ключ aibal.ai на адрес изображения.

### Запрос редактирования изображения

Замените `/path/to/reference.png` реальным путём к файлу. Используется отправка формы; не задавайте заголовок `Content-Type` для JSON.

```bash
curl --fail-with-body https://aibal.ai/v1/images/edits \
  -H "Authorization: Bearer $AIBAL_API_KEY" \
  -F "image[]=@/path/to/reference.png" \
  --form-string "model=gpt-image-2" \
  --form-string "prompt=Keep the subject and replace the background with light blue" \
  --form-string "n=1" \
  --form-string "output_format=png" \
  --form-string "background=auto" \
  -o image-response.json
```

Для нескольких референсов повторите `-F "image[]=@..."`. Сохранение результата выполняется так же, как при генерации из текста.

### Особенности использования в Codex

#### Клиенты с обработчиком генерации изображений

Для ключей группы OpenAI в панели доступны две конфигурации Codex: **Режим совместимости** и **Режим API-ключа** (API Key Mode). Первый сохраняет настройку для старых клиентов, а второй авторизует обработчик изображений в клиентах, поддерживающих эту возможность.

<Steps>
  <Step title="Откройте конфигурацию ключа">
    В списке API-ключей aibal.ai найдите ключ группы OpenAI, нажмите **Использовать ключ** и выберите **Codex CLI**.
  </Step>
  <Step title="Выберите режим API-ключа">
    В разделе **Режим аутентификации Codex** выберите **Режим API-ключа**, затем свою операционную систему. Этот вариант отображается только для соответствующих группы и клиента.
  </Step>
  <Step title="Сохраните полную конфигурацию">
    Сохраните сформированную конфигурацию по инструкции окна. Если требуется файл каталога моделей, сохраните и его. Сначала сделайте резервную копию настроек; не смешивайте эту схему с ручным `env_key` или фрагментами `auth.json` из режима совместимости. Скопированные настройки содержат настоящий ключ — храните их приватно на своём устройстве.
  </Step>
  <Step title="Полностью перезапустите клиент и создайте задачу">
    Полностью закройте Codex Desktop или CLI, откройте снова и создайте новую задачу. Обновления старой задачи или продолжения сеанса недостаточно для повторной инициализации, требуемой панелью.
  </Step>
</Steps>

Этот порядок подходит клиентам с соответствующим обработчиком изображений и не гарантирует встроенную генерацию в каждой версии Codex. Проверьте доступные инструменты своего клиента. Успешный текстовый диалог сам по себе не подтверждает настройку изображений.

#### Явный вызов API изображений

Также можно поручить Codex вызвать приведённый выше API aibal.ai и сохранить результат локально. Так вы явно задаёте адрес, модель и путь файла, не полагаясь на автоматический выбор встроенного инструмента.

Пример задания:

```text
Создай одну акварельную иллюстрацию котёнка через https://aibal.ai/v1/images/generations.
Прочитай AIBAL_API_KEY из окружения. Используй model gpt-image-2, n=1, output_format=png; не задавай size.
Отправь только один запрос генерации. Не повторяй его автоматически при обрыве соединения или неясном результате.
Декодируй b64_json или скачай возвращённый url и сохрани файл как assets/kitten.png в проекте.
Не выводи API-ключ, не записывай его в исходный код и не включай в итоговый ответ.
```

Убедитесь, что среда выполнения видит переменную и может обращаться к сети. Если клиент не выполняет запросы, запустите команды в локальном терминале. Подключение чата описано на странице [Codex](/ru/codex).

## Частые вопросы

### Нет активного ключа или недостаточно прав

Проверьте, что ключ включён, не просрочен, не исчерпал лимит и относится к группе с доступом к модели изображений. Вход в аккаунт не даёт такого доступа каждому ключу. См. [Создание API-ключа](/ru/create-api-key).

### Почему недоступны фиксированные размеры?

Страница отключает размеры, которые сейчас не могут быть возвращены в заданном виде. Оставьте **Авто** и проверьте размеры готового файла. Не обходите ограничения изменением параметров запроса.

### Что делать при ошибке, ограничении частоты или неизвестном результате?

При ошибке оплаты проверьте баланс и лимит ключа; при ошибке ввода — формат, референсы и модель. При ограничении частоты подождите; после отказа модерации измените описание или материалы. Если результат и списание неизвестны, сначала проверьте [историю использования](https://aibal.ai/usage). Для поддержки сохраните ID запроса и код ошибки, но не отправляйте полный ключ.

### Можно ли делиться скопированной командой curl?

Не отправляйте её без проверки. **Пример API (curl)** на странице может содержать полный ключ. Перед передачей замените его переменной окружения и проверьте историю буфера обмена и снимки экрана.

Далее попробуйте [генерацию видео](/ru/text-to-video) или прочитайте [обзор подключения](/ru/integrations).
