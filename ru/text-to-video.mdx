Опишите сцену, чтобы создать задачу генерации видео. Обработка выполняется асинхронно: после принятия запроса нужно дождаться завершения, прежде чем воспроизводить или скачивать видео.

## Перед началом

- Войдите в [aibal.ai](https://aibal.ai/login) и подготовьте активный [API-ключ](/ru/create-api-key), группа которого поддерживает видео.
- Проверьте баланс аккаунта и лимит ключа; при необходимости [пополните баланс](/ru/recharge). Генерация через сайт и API оплачивается.
- Начните с короткого ролика. Цены, доступные услуги и лимиты указаны в текущей панели управления.

<Steps>
  <Step title="Откройте страницу «Текст в видео»">
    Откройте [генерацию видео](https://aibal.ai/video-studio) и выберите **API Key**. Сейчас страница использует фиксированную модель `seedance-2`.
  </Step>
  <Step title="Выберите основные параметры">
    Для первой попытки установите **Длительность: 4 с**, **Соотношение сторон: 1:1**, **Разрешение: 480p**. На телефоне нажмите **Параметры видео**, если панель свёрнута.
  </Step>
  <Step title="Введите промпт">
    Опишите объект, движение, сцену и камеру. Например: «Синий куб медленно вращается на чистом белом фоне, мягкий студийный свет, неподвижная камера, простая композиция, без текста».

    **Изображение первого кадра** сейчас недоступно; загружать картинку не нужно.
  </Step>
  <Step title="Отправьте запрос и подождите">
    Нажмите **Создать видео** и следите за автоматическим обновлением статуса в разделе **Результат**. Не отправляйте один запрос несколько раз и не считайте очередь или обработку ошибкой.
  </Step>
  <Step title="Просмотрите и скачайте">
    Когда появится **Готово**, воспроизведите ролик. Нажмите **Скачать видео**. Если откроется страница воспроизведения, используйте сохранение в проигрывателе или браузере. Также доступно **Открыть в новом окне**.
  </Step>
  <Step title="Проверьте предыдущие задачи">
    Выберите запись в разделе **История задач**, чтобы увидеть промпт, параметры, статус и результат. Ориентируйтесь на статус, полученный при запросе задачи; закрытие браузера её не отменяет.
  </Step>
</Steps>

### Параметры

| Поле | Текущий режим |
| --- | --- |
| **Модель** | В веб-интерфейсе используется `seedance-2`. |
| **Длительность** | От 4 до 15 секунд с шагом в одну секунду. |
| **Соотношение сторон** | `1:1` — квадрат, `16:9` — горизонтальное видео, `9:16` — вертикальное. |
| **Разрешение** | `480p`, `720p` или `1080p`; более высокие параметры могут увеличить стоимость и время. |
| **Промпт** | Обязателен. Ясно опишите объект, движение и сцену. |
| **Первый кадр / аудио** | В этом сценарии поддерживается только текст; первый кадр и генерация аудио недоступны. |

## Создание видео через API

Используйте `curl` и безопасно задайте переменную окружения `AIBAL_API_KEY`. Следующий запрос создаёт реальную задачу и может привести к списаниям.

<Note>
Адрес для `seedance-2` — `/api/v3/contents/generations/tasks`, без `/v1`. Не переносите сюда адрес или тело запроса от другой модели видео.
</Note>

### 1. Создайте задачу

```bash
curl --fail-with-body https://aibal.ai/api/v3/contents/generations/tasks \
  -H "Authorization: Bearer $AIBAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2",
    "content": [{"text": "A blue cube rotates slowly on a clean white background, fixed camera"}],
    "duration": 4,
    "resolution": "480p",
    "ratio": "1:1",
    "generate_audio": false
  }' \
  -o video-task.json
```

`content` должен содержать ровно один текстовый элемент. Параметры соответствуют первой попытке в браузере; `generate_audio` должен быть `false`. Не используйте здесь `seedance-2-fast` или пропорции `adaptive`.

Ответ сохраняется в `video-task.json` в текущем каталоге. Откройте файл и сохраните `id` для последующих запросов. Успешный HTTP-ответ означает получение информации о задаче; завершение определяется по `status`.

Если программа повторяет запрос создания, добавьте заголовок `Idempotency-Key`: для каждой новой задачи задавайте уникальное значение, а при повторе той же задачи сохраняйте значение и тело запроса. Не меняйте ключ только потому, что запрос завершился по тайм-ауту.

### 2. Проверьте статус

Замените заполнитель на полученный `id` и используйте исходный API-ключ:

```bash
AIBAL_VIDEO_TASK_ID="REPLACE_WITH_TASK_ID"
curl --fail-with-body \
  "https://aibal.ai/api/v3/contents/generations/tasks/$AIBAL_VIDEO_TASK_ID" \
  -H "Authorization: Bearer $AIBAL_API_KEY" \
  -o video-status.json
```

Откройте `video-status.json` и прочитайте возвращённый `status`. Проверяйте статус примерно раз в 5 секунд; при временной ошибке запроса увеличьте интервал. Не создавайте новую задачу вместо проверки существующей.

| `status` | Что делать |
| --- | --- |
| `accepted`, `submitting`, `submitted`, `queued`, `running` | Обработка продолжается; повторите проверку позже. |
| `succeeded` | Прочитайте `content.video_url`. |
| `failed`, `expired` | Прекратите опрос и проверьте `error.code` и `error.message`. |
| `unknown_submission` | Результат отправки неизвестен. Остановите автоматические повторы, проверьте задачи и использование, при необходимости обратитесь в поддержку. |

### 3. Сохраните видео

При успехе ответ содержит `content.video_url`. Откройте ссылку или подставьте её в команду:

```bash
AIBAL_VIDEO_URL="REPLACE_WITH_CONTENT_VIDEO_URL"
curl --fail --location "$AIBAL_VIDEO_URL" --output generated-video.mp4
```

Не добавляйте API-ключ aibal.ai к запросу скачивания. Сохраните файл сразу; не используйте ссылку результата как постоянное хранилище.

## Частые вопросы

### Кнопка недоступна или нет подходящего ключа

Выберите активный ключ и введите промпт. Группа ключа должна разрешать видео; баланс или доступ к текстовым моделям сами по себе недостаточны.

### Можно ли отменить отправленную задачу?

Отмена видеозадач сейчас не поддерживается. Закрытие или обновление страницы и прерывание локального запроса не отменяют уже отправленную задачу. Проверяйте описание и параметры до отправки.

### Задача завершена, но видео не воспроизводится

Попробуйте **Открыть в новом окне**, затем скачать файл. Если результат всё ещё недоступен, сохраните ID задачи и сведения об ошибке для поддержки. Не создавайте такую же задачу сразу ради новой ссылки.

### Что делать при недостаточном балансе, неверных параметрах или неизвестном статусе?

При ошибке оплаты проверьте баланс и лимит ключа; при ошибке ввода — модель, длительность, пропорции и разрешение. При `unknown_submission` или тайм-ауте сначала проверьте **История задач** и [историю использования](https://aibal.ai/usage), чтобы избежать повторных задач и расходов.

<Warning>
Не публикуйте полные API-ключи, команды с ключами и приватные ссылки на видео. Для поддержки достаточно ID задачи, кода ошибки и описания без чувствительных данных.
</Warning>
