CC Switch управляет конфигурациями провайдеров для инструментов программирования. Это не сервис моделей и не замена установке Codex или Claude Code. Ниже два инструмента настраиваются отдельно — выберите нужный.

## Перед началом

- [Создайте API-ключ](/ru/create-api-key) с подходящей группой и моделью для выбранного инструмента.
- Скачайте установщик для своей операционной системы и архитектуры процессора из [официальных Releases CC Switch](https://github.com/farion1231/cc-switch/releases) и следуйте его инструкции.
- Установите [Codex CLI](/ru/codex) или [Claude Code](/ru/claude-code).

При первом запуске сохраните или импортируйте существующие настройки, прежде чем менять их. Названия и расположение кнопок могут отличаться в разных версиях CC Switch.

## Добавление провайдера aibal.ai

<Steps>
  <Step title="Выберите приложение">
    Откройте CC Switch и выберите **Codex** или **Claude Code** в переключателе приложений. Используйте провайдера для конкретного приложения, чтобы каждый инструмент сохранял собственные настройки.
  </Step>
  <Step title="Откройте форму добавления">
    Нажмите **+** / **Добавить провайдера** справа вверху, выберите провайдера для конкретного приложения, затем **Пользовательский**. Укажите имя `aibal.ai - Codex` или `aibal.ai - Claude Code`.
  </Step>
  <Step title="Заполните настройки клиента">
    Используйте раздел **Настройка Codex** или **Настройка Claude Code** ниже. Если консоль в разделе **Использовать ключ** предлагает отдельный адрес, используйте его. Базовые адреса двух клиентов различаются — не копируйте один вместо другого.
  </Step>
  <Step title="Сохраните и включите">
    Нажмите **Добавить**, вернитесь на главный экран и нажмите **Включить** у нового провайдера. Закройте прежний сеанс клиента и заново запустите нужный CLI, чтобы он прочитал новую конфигурацию.
  </Step>
  <Step title="Проверьте первый запрос">
    Попросите инструмент: «Ответь только „Подключение успешно“. Не читай и не изменяй файлы, не выполняй команды». Затем проверьте ключ, модель и время в **Истории использования** aibal.ai. Сохранение настроек ещё не подтверждает успешный вызов; проверочное сообщение может быть платным.
  </Step>
</Steps>

## Настройка Codex

Выберите **Codex** и заполните форму или редактор конфигурации:

| Поле | Значение |
| --- | --- |
| Имя | `aibal.ai - Codex` |
| API Key | Ключ aibal.ai для выбранной группы |
| Base URL / адрес | `https://aibal.ai/v1` |
| Модель | Полный идентификатор доступной текстовой модели из консоли |
| Протокол | `responses` |

Если ваша версия предлагает редакторы **auth.json** и **config.toml**, используйте эти согласованные примеры. Замените заполнители ключа и модели и сохраняйте настройки только в локальном CC Switch.

`auth.json`:

```json
{
  "OPENAI_API_KEY": "YOUR_AIBAL_API_KEY"
}
```

`config.toml`:

```toml
model_provider = "aibal"
model = "YOUR_AVAILABLE_MODEL_ID"

[model_providers.aibal]
name = "aibal.ai"
base_url = "https://aibal.ai/v1"
wire_api = "responses"
requires_openai_auth = true
supports_websockets = false
```

Здесь используется способ с ключом в `auth.json` из официальной инструкции CC Switch, поэтому `requires_openai_auth = true`. Не добавляйте одновременно `env_key` из [ручной настройки Codex](/ru/codex): это другой способ авторизации. Если группе нужен файл каталога моделей, выполните соответствующие шаги в разделе **Использовать ключ**.

## Настройка Claude Code

Выберите **Claude Code**, укажите имя `aibal.ai - Claude Code` и вставьте в редактор пользовательской конфигурации:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://aibal.ai",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_AIBAL_API_KEY",
    "ANTHROPIC_MODEL": "YOUR_AVAILABLE_CLAUDE_MODEL_ID"
  }
}
```

Замените оба заполнителя: ключом aibal.ai и моделью Claude, поддерживаемой его группой. Этот адрес не содержит `/v1`. Запустите Claude Code и выполните `/status`, чтобы проверить адрес шлюза и источник учётных данных.

## Переключение и восстановление

Найдите провайдера в нужном приложении, нажмите **Включить** и начните новый сеанс. У Codex и Claude Code разные конфигурации: переключение одного не переключает другой.

Чтобы вернуться к прежнему сервису, включите сохранённого провайдера. Для входа в официальный аккаунт выберите предустановку **Официальный вход** и следуйте процедуре клиента. Не удаляйте все настройки ради восстановления.

## Частые вопросы

### Клиент всё ещё использует прежний сервис

Проверьте выбранное приложение, убедитесь, что провайдер включён, и перезапустите клиент. Переменные окружения или общие настройки CC Switch могут переопределять значения провайдера. В дальнейшем редактируйте настройки в одном месте.

### Список моделей пуст или автоматическое получение не работает

Доступные модели зависят от группы ключа. Проверьте ключ и адрес или вручную введите полный идентификатор из раздела **Использовать ключ**. Не подставляйте название модели другого сервиса.

### Почему у Codex и Claude Code разные адреса?

Клиенты по-разному формируют путь запроса. В этом руководстве Codex использует базовый адрес с `/v1`, а Claude Code — корень сайта. Лишний или отсутствующий фрагмент пути может привести к `404`.

### Можно ли делиться экспортированными настройками?

Конфигурации провайдеров и резервные копии могут содержать настоящие API-ключи. Не публикуйте их в репозиториях, чатах или ненадёжных хранилищах синхронизации. Передавайте только шаблоны с заменёнными ключами; при утечке немедленно отключите ключ.

Ошибки подключения рассмотрены в [обзоре интеграций](/ru/integrations). Возможности и текущий интерфейс CC Switch описаны в [официальном руководстве](https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/zh/README.md).
