---
title: "Integration overview"
description: "Connect aibal.ai to common clients"
---

Use `https://aibal.ai/v1`, a key created in the console, and a currently available model.

- **cc-switch**: add a custom provider with the base URL and key, then send a short test request.
- **Codex**: configure the provider base URL and a dedicated development key.
- **Claude Code**: set the provider environment values and verify the key's group permissions.
- **Web**: sign in and use Image Studio or Video Studio without configuring a client.

Keep keys in environment variables or a secret manager.
