---
title: "Text to image (web and API)"
description: "Generate images online or through the compatible API"
---

Use **Image Studio** for a first test. For API clients, send a supported model and prompt to `https://aibal.ai/v1/images/generations` with a Bearer key. Codex users should configure `https://aibal.ai/v1` as the provider base URL and keep the key outside prompts and source code.
