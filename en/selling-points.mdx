aibal.ai helps reduce repeated setup so you can focus on creating and building. Try a workflow in the browser, connect a tool or application when needed, and review usage in the same console.

## Manage everything in one account

Top up your balance, create API keys, review usage, and manage existing entitlements in one place. Moving between workflows does not require learning another account management interface.

For example, use separate keys for daily coding, image assets, and test scripts, then review their usage records.

## Move from browser trials to API use

Start with [image generation](/en/text-to-image) or [video generation](/en/text-to-video). For repeatable tasks or an integration in your product, use the API examples in those guides.

Both browser and API requests must meet service group, balance, and quota requirements. A browser trial does not mean a free request.

## Work with your existing coding tools

Follow the [cc-switch](/en/cc-switch), [Codex](/en/codex), or [Claude Code](/en/claude-code) guide. Choose visual configuration management or direct client configuration.

Different tools use different protocols and URL formats. Each guide explains the required address, including whether to add `/v1`.

## Review usage and costs

Use **Dashboard** for an overview and **Usage** for available model, token, and cost details. Begin with a small task, check the result and actual cost, then decide how much to use.

Image and video billing may differ from text model billing. Check current service prices, multipliers, and rules rather than assuming one price or discount applies to every model.

## Separate keys by purpose

Create a dedicated API key for each project and set its quota and expiry. Configure IP or rate limits when needed to reduce the impact of misuse.

A key quota controls that key's spending; it does not add account balance. Changing keys does not bypass group permissions or account limits.

## Suitable workflows

| Scenario | Recommended approach |
| --- | --- |
| Learning and personal creation | Start with a [web trial](/en/web-quickstart) to understand results and costs |
| Everyday AI coding | Select an [integration guide](/en/integrations) and use a dedicated coding key |
| Scripts and automation | Use the relevant API, retain request or task identifiers, and avoid blind retries when the outcome is unclear |
| Multiple projects | Use separate keys for projects or environments with suitable quotas and expiry; do not share the main account password with everyone |

## Check three things before you start

1. **Capability**: the selected group must provide your intended model and feature.
2. **Cost**: review balance, key quota, pricing, and expiry for your task.
3. **Result**: use a small request to check output quality and tool compatibility.
