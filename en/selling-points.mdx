aibal.ai brings account management, balance, API keys, model access, and usage records into one workspace. Available models, groups, prices, and limits are always defined by the signed-in console.

## Core advantages

- One account for balance, keys, usage, and online tools.
- OpenAI-compatible API access for supported services.
- Separate keys, groups, quotas, and expiry dates for each workflow.
- Online image and video tools for a quick first test.

Start with registration, add balance, create a key, and run a small request before configuring a client.
