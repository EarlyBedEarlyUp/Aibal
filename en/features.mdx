## Unified model routing

aibal.ai provides one routing layer between your application and upstream AI providers. Use the platform model identifier in your application while you manage providers, priorities, and failover rules from the dashboard.

## Providers and models

A provider is an upstream credential or service connection. Configure separate providers for different environments and control which models are available to each project. After changing a provider, use a test key to verify responses, latency, and error rates.

## Groups and limits

Groups isolate projects, teams, and tenants. Each group can have its own keys, model allowlist, concurrency limit, daily budget, or monthly budget. Bind keys to the smallest group that meets the application's needs.

## Usage and logs

Review request counts, token usage, latency, and errors in the dashboard. Combine these records with application logs when investigating failed or unexpectedly expensive requests.
