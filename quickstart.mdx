---
title: "开始使用 aibal.ai"
description: "准备账户、余额和 API Key，选择适合你的第一次体验"
---

完整三语指南：[中文](/zh/platform-overview) · [English](/en/platform-overview) · [Русский](/ru/platform-overview)。

<Steps>
  <Step title="注册并登录">
    打开 [aibal.ai](https://aibal.ai/)，按[注册账户](/zh/register)中的截图与步骤完成注册。
  </Step>
  <Step title="准备可用余额或权益">
    核对要使用的服务分组与费用；需要补充余额时，按[充值指南](/zh/recharge)使用 USDT 或余额兑换码。
  </Step>
  <Step title="创建 API Key">
    按[创建 API Key](/zh/create-api-key)选择支持目标能力的分组，并设置合适的额度与有效期。
  </Step>
  <Step title="开始体验">
    不安装软件可以选择[网页端快速体验](/zh/web-quickstart)。需要接入工具时，选择 [cc-switch](/zh/cc-switch)、[Codex](/zh/codex) 或 [Claude Code](/zh/claude-code)。
  </Step>
</Steps>

第一次使用后，查看结果和控制台 **使用记录**，确认费用符合预期。不要把登录密码当成 API Key，也不要把真实密钥放入聊天、截图或公开代码中。
