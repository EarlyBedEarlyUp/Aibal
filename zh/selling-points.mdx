# aibal.ai 是什么

aibal.ai 是面向个人开发者、团队和业务应用的 AI 接入平台。你可以在一个账户中管理余额、充值、兑换码、API Key、模型调用和用量明细，并通过统一接口接入当前开放的 AI 服务。

## 核心优势

- **一个账户统一管理**：注册、充值、API Key 和调用记录集中在同一个控制台。
- **按实际使用量核对**：请求、输入输出 Token、模型和费用明细可以在控制台查询。
- **在线能力与 API 并行**：文生图、文生视频等功能可先在网页端试用，再接入自己的工具或应用。
- **面向常用工作流**：提供适合 cc-switch、Codex、Claude Code 以及网页端快速验证的接入方式。
- **配置边界清晰**：不同 API Key 可以绑定不同服务分组、额度和有效期，便于区分个人、测试和生产环境。

## 使用前说明

站点实际开放的模型、服务分组、价格、倍率、额度和有效期，以登录后的控制台和商品详情为准。本文只描述当前项目已经实现的用户操作，不承诺未在控制台展示的第三方能力。

<Callout type="info" title="推荐顺序">
先注册并充值，再创建 API Key。第一次接入建议先在网页端完成一次最小调用，确认模型、额度和费用后再配置客户端。
</Callout>
