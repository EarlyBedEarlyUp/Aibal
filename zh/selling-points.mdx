title: "核心优势"
description: "把 AI 创作、工具接入和费用管理放在同一个工作流中"
---

aibal.ai 帮你减少重复配置，把注意力放回创作和开发本身。先在网页端验证效果，再按需要接入工具或应用，在同一个控制台查看使用情况。

## 一个账户，集中管理

你可以在同一处完成充值、创建 API Key、查看使用记录和管理已有权益。切换工作流时，不必重新熟悉一套账户管理方式。

例如，为日常编程、图片素材和测试脚本分别创建密钥，再通过使用记录核对各自的用量。

## 从网页体验到程序接入

想先看效果，可以使用[图片生成](/zh/text-to-image)和[视频生成](/zh/text-to-video)。需要重复执行或整合进产品时，再使用文档中的 API 示例。

网页和 API 都需要符合服务分组、余额和额度要求；在线体验不是免费调用的同义词。

## 配合你已有的开发工具

文档提供 [cc-switch](/zh/cc-switch)、[Codex](/zh/codex) 和 [Claude Code](/zh/claude-code) 接入说明。你可以选择可视化配置管理，或直接编辑客户端配置。

不同工具使用的协议和地址格式不同。按照各自指南填写，不需要猜测应不应该加 `/v1`。

## 用量与费用可以核对

在 **仪表盘** 查看整体使用情况，在 **使用记录** 核对模型、Token 和费用等页面提供的信息。第一次尝试建议使用较小任务，先看结果和实际消费，再决定后续用量。

图片和视频的计费方式可能与文字模型不同；价格、倍率与适用规则以当前服务说明为准，不用固定折扣或统一单价估算所有模型。

## 密钥按用途分开管理

每个项目可以使用独立 API Key，并设置额度和有效期。需要时再配置 IP 或速率限制，降低误用影响。

密钥限额用于控制该密钥的消费范围，不会自动增加账户余额；更换密钥也不会绕过分组权限或账户限制。

## 适合哪些使用场景

| 场景 | 推荐做法 |
| --- | --- |
| 个人学习与创作 | 先完成一次[网页体验](/zh/web-quickstart)，了解结果与费用 |
| 日常 AI 编程 | 按工具选择[接入指南](/zh/integrations)，单独创建编程用 Key |
| 脚本与自动化 | 使用对应 API，保存请求或任务标识，避免不明确结果下盲目重试 |
| 多项目协作 | 为项目或环境分别创建 Key，按需要设置额度和有效期；不要把主账户密码共享给所有人 |

## 使用前核对三件事

1. **能力是否适用**：目标模型和功能是否在所选分组中开放。
2. **成本是否清楚**：余额、Key 额度、价格与有效期是否满足当前任务。
3. **结果是否符合需要**：先用一次小规模请求验证效果和工具兼容性。
