aibal.ai 是面向个人开发者、内容创作者和团队的 AI 服务平台。你可以先在浏览器里生成图片或视频，也可以把 API Key 配置到编程工具、脚本和自己的应用中。

在同一个账户中，你可以充值、管理 API Key、选择可用服务分组和查看使用记录。产品入口为 [aibal.ai](https://aibal.ai/)。

<Info>
可用模型、服务分组、价格和额度以控制台当前展示为准。注册账户不代表已获得所有模型权限，也不代表每次调用免费。
</Info>

## 第一次使用

<Steps>
  <Step title="注册并登录">
    按[注册账户](/zh/register)完成邮箱和密码设置，登录后进入控制台。
  </Step>
  <Step title="确认服务与余额">
    查看你要使用的模型与服务分组。如果需要补充余额，按[充值账户](/zh/recharge)使用 USDT 或余额兑换码；如已有可用权益，先核对适用范围。
  </Step>
  <Step title="创建用途明确的密钥">
    在 **API 密钥** 中创建一个密钥，选择支持目标能力的分组。不同工具或项目建议使用不同密钥。
  </Step>
  <Step title="完成一次小规模尝试">
    从[网页端快速体验](/zh/web-quickstart)开始，或选择对应的[工具接入指南](/zh/integrations)。成功后查看结果与使用记录，再扩大使用量。
  </Step>
</Steps>

## 先分清这几个概念

- **账户**：用于登录网页和管理你的服务。
- **API Key**：用于客户端或脚本调用服务，不是登录密码。
- **服务分组**：决定密钥可使用的服务范围及相应规则；同一账户下的不同密钥不一定支持相同模型。
- **余额与权益**：决定可消费的资源。密钥还可能有独立额度、有效期和速率限制。
- **模型**：请求中实际调用的能力，名称应从控制台或该分组的接入说明复制。

## 常见问题

### 需要先安装软件吗？

网页端图片和视频生成只需浏览器。接入 Codex、Claude Code 或 cc-switch 时，再按对应页面安装工具。

### 这是模型厂商的官方网站吗？

aibal.ai 提供自己的 AI 服务接入入口。aibal.ai 账户、余额和 API Key 不等于 OpenAI 或 Anthropic 官方账户与订阅，也不会自动增加这些厂商账户的权益。

### 第一次应该从哪里开始？

如果你还没有账户，先[注册](/zh/register)；如果已经有可用余额和密钥，直接打开[网页端快速体验](/zh/web-quickstart)。
