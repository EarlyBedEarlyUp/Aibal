## 创建步骤

1. 登录 [aibal.ai 控制台](https://aibal.ai)。
2. 打开 **API Key** 或 **API 密钥** 页面。
3. 点击创建，填写用途名称，例如 `local-test`、`cc-switch` 或 `production-api`。
4. 选择服务分组、可用模型、额度和有效期。
5. 提交后立即复制完整密钥，并保存到密码管理器或环境变量中。

完整密钥通常只在创建成功后显示一次。不要把它放进前端代码、公开仓库、截图或聊天记录。

## 推荐的密钥划分

| 用途 | 建议 |
| --- | --- |
| 网页快速尝试 | 单独创建短期、低额度密钥 |
| cc-switch / Codex | 单独创建开发密钥，便于随时撤销 |
| Claude Code | 单独创建密钥，并确认服务分组支持对应协议 |
| 生产应用 | 使用独立密钥、最小权限和明确有效期 |

发现泄露时，立即撤销旧 Key 并创建新 Key。不要通过修改客户端名称来“隐藏”已泄露的密钥。
