API Key 是客户端调用 aibal.ai 的凭证。建议为每个工具或应用创建独立密钥，便于查看用量、调整限制和停用访问。

## 开始前

- 已完成[注册并登录](/zh/register)。
- 确认账户有要使用的分组，以及对应余额或有效订阅。需要时先[充值账户](/zh/recharge)。
- 明确用途，例如 `codex-work`、`claude-dev` 或 `image-api`。名称只便于识别，不会自动选择协议或模型。

<Steps>
  <Step title="打开 API 密钥页面">
    在控制台点击 **API 密钥**，或直接打开[密钥页面](https://aibal.ai/keys)，点击 **创建密钥**。
  </Step>
  <Step title="填写用途名称">
    在 **名称** 中填写便于识别的名称。为不同客户端使用不同名称，方便之后找到对应密钥。
  </Step>
  <Step title="选择厂商与分组">
    先选择 **厂商**，再在 **分组** 中选择当前账户可用的服务分组。阅读分组说明和计费倍率，确认支持你计划使用的模型及接入方式。

    分组不能为空。创建页面不单独选择模型，模型在后续客户端或请求中指定。厂商灰显时，表示当前账户没有该厂商可选的分组；不要为此随意改选不匹配的服务。
  </Step>
  <Step title="设置额度、有效期和可选限制">
    首次使用建议在 **额度限制** 中填写适合本次用途的金额上限，并开启 **密钥有效期**。需要限制固定服务器访问时，再配置 **IP 限制**。

    通常保留 **自定义密钥** 关闭，由系统生成密钥。其他选项见下方说明。
  </Step>
  <Step title="创建并复制密钥">
    检查设置后点击 **创建**。看到成功提示后，在列表找到刚才的名称，点击密钥旁的复制按钮。

    列表中的密钥文字会脱敏显示，复制按钮会复制完整值。将它保存到密码管理器、客户端的安全凭证设置或本机环境变量中。
  </Step>
  <Step title="查看接入配置">
    点击该行的 **使用密钥**，查看适合当前分组的客户端配置。按目标客户端要求填写 API 地址和密钥，不要对所有客户端套用同一种地址格式。

    完成配置后，先发起一次小请求，再检查 **使用记录** 与密钥用量。实际请求可能产生费用。
  </Step>
</Steps>

## 字段与限制说明

| 字段 | 用途与建议 |
| --- | --- |
| 名称 | 标识用途，不决定模型或权限 |
| 厂商 / 分组 | 筛选并选择分组；可选项、模型和倍率以当前控制台为准 |
| 自定义密钥 | 可选；至少 16 个字符，仅支持字母、数字、下划线和连字符。建议交由系统生成 |
| IP 白名单 | 开启 IP 限制后，每行一个 IP 或 CIDR；只允许列出的来源地址访问 |
| IP 黑名单 | 每行一个 IP 或 CIDR；阻止列出的来源地址访问 |
| 额度限制 | 此密钥可消费的总金额，单位为 USD；0 表示不单独限制 |
| 速率限制 | 5 小时、1 天、7 天窗口的消费金额上限，单位为 USD，并非每秒请求数；0 表示该窗口不单独限制 |
| 密钥有效期 | 选择快捷天数或自定义过期时间；关闭时不设置密钥过期时间 |

<Note>
密钥额度不是充值余额。设置 10 USD 的上限不会给账户增加 10 USD；不设置密钥限制也不代表免费或无限可用。账户余额、订阅额度、分组限制和密钥限制仍需同时满足。
</Note>

## 创建后的检查与管理

- 确认状态为 **活跃**，分组和有效期正确。
- 从列表查看用量和额度，在 **使用记录** 中核对具体请求。
- 需要调整时使用 **编辑密钥**。更换分组后，重新检查客户端模型和协议是否兼容。
- 临时停止访问时使用 **禁用**；不再需要时使用 **删除密钥**。删除无法撤销，原客户端将无法继续使用该密钥。

下一步可以选择 [cc-switch](/zh/cc-switch)、[Codex](/zh/codex)、[Claude Code](/zh/claude-code)，或先做一次[网页端快速体验](/zh/web-quickstart)。

## 常见问题

### 为什么没有可选分组？

切换到你要使用的厂商，确认账户拥有对应分组或订阅。不要随意选择不匹配的分组，没有合适选项时通过站内联系方式咨询。

### 创建后还能复制密钥吗？

可以在 **API 密钥** 列表中使用复制按钮。页面的脱敏字符串不能代替完整密钥。不要为了查看完整值将密钥粘贴到聊天或截图中。

### 账户有余额，为什么仍然调用失败？

检查密钥是否停用、过期、额度耗尽，或达到窗口消费上限。再核对分组、模型、API 地址和 IP 限制；有账户余额不代表当前分组或订阅一定可用。

### 开启 IP 白名单后无法使用？

应填写请求的公网出口 IP，而不是通常以 `192.168` 或 `10` 开头的本机内网地址。VPN、代理、移动网络可能改变出口 IP；先确认网络条件再设置白名单。

### 密钥泄露了怎么办？

立即禁用或删除旧密钥，创建新密钥并更新所有客户端。查看近期使用记录，核实异常费用。只修改名称或删除截图，不能撤销已经泄露的访问权限。

<Warning>
API Key 与密码一样敏感。不要放入网页前端代码、公开仓库、日志、截图或群聊，也不要把完整密钥发给支持人员。服务端应用应从安全配置或环境变量读取密钥。
</Warning>
