## 创建账户

1. 打开 [aibal.ai](https://aibal.ai)，点击 **立即开始** 或 **注册**。
2. 填写邮箱、密码和页面要求的信息。
3. 按页面提示完成验证，然后返回登录页。
4. 登录后进入控制台，先查看当前开放的服务分组和使用规则。

## 注册后的检查

- 确认账户邮箱可以正常接收通知。
- 查看控制台显示的余额、服务方案和可用模型。
- 阅读当前服务分组的额度、有效期和计费说明。

注册本身不会自动创建 API Key，也不会替你选择服务方案。充值和创建密钥分别按照后续页面操作。
