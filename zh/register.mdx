通过邮箱注册 aibal.ai 账户。注册完成后，你可以进入控制台查看当前开放的服务、模型和计费规则。

</Frame>

## 开始前

- 准备一个可以接收邮件的邮箱。验证码会发送到这个邮箱。
- 密码至少需要 6 个字符。建议使用未在其他网站重复使用的密码。
- 邀请码和优惠码按页面显示填写，均为可选项；没有时可以留空。

## 注册步骤

<Steps>
  <Step title="打开注册页面">
    打开 [aibal.ai](https://aibal.ai)。点击首页的 **立即开始**，在登录页点击 **注册**。

    也可以直接打开 [注册页面](https://aibal.ai/register)。
  </Step>
  <Step title="填写邮箱">
    在 **邮箱** 输入框中填写常用邮箱地址。请确认地址拼写正确，并且你可以访问该邮箱。
  </Step>
  <Step title="设置并确认密码">
    在 **密码** 中设置至少 6 个字符的密码，然后在 **确认密码** 中再次输入。两次输入必须完全一致。

    点击输入框右侧的眼睛图标，可以临时查看输入内容，便于检查拼写。
  </Step>
  <Step title="填写可选代码">
    如果你有邀请或优惠代码，可以分别填写 **邀请码** 和 **优惠码**。没有代码时直接跳过，不影响继续注册。
  </Step>
  <Step title="发送验证邮件">
    点击 **继续**。系统会向注册邮箱发送验证码，并打开邮箱验证页面。

    如果页面提示注册不可用、邮箱域名不支持或代码无效，请按页面提示修改后重试。
  </Step>
  <Step title="完成邮箱验证">
    打开注册邮箱，找到 aibal.ai 发出的验证邮件，复制邮件中的 6 位验证码。

    返回验证页面，在验证码输入框中输入数字，点击 **验证并创建账户**。收不到邮件时，先检查垃圾邮件文件夹，再使用 **重新发送验证码**。
  </Step>
  <Step title="进入控制台">
    验证成功后，系统会自动创建账户并进入控制台。首次进入时，先查看当前可用的服务分组、模型、余额和计费说明。
  </Step>
</Steps>

## 注册页面字段说明

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 邮箱 | 是 | 用于接收验证码和账户通知 |
| 密码 | 是 | 至少 6 个字符 |
| 确认密码 | 是 | 再次输入相同密码 |
| 邀请码 | 否 | 有邀请关系时填写 |
| 优惠码 | 否 | 有有效优惠活动时填写 |

## 注册后的检查

1. 确认账户邮箱可以正常接收通知。
2. 查看控制台显示的余额、服务方案和可用模型。
3. 阅读当前服务分组的额度、有效期和计费说明。
4. 按照 [创建 API Key](/zh/create-api-key) 的说明创建调用密钥。

注册不会自动创建 API Key，也不会替你选择服务方案。充值和创建密钥请按照对应页面操作。

## 常见问题

### 收不到验证码怎么办？

先检查垃圾邮件、广告邮件或邮件拦截规则，并确认注册时填写的邮箱地址没有拼写错误。等待一段时间后，可以点击 **重新发送验证码**。不要连续快速点击发送按钮。

### 邀请码或优惠码可以之后补填吗？

请以注册页面和当前活动规则为准。需要使用代码时，建议在点击 **继续** 前填写并等待页面完成校验。

### 注册成功后下一步做什么？

先在控制台确认服务分组和余额，再创建 API Key。不要把密码、邮箱验证码或 API Key 发布到截图、代码仓库或聊天记录中。
