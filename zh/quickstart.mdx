## 准备工作

你需要一个已验证的 aibal.ai 账户、至少一个已启用的模型渠道，以及一个用于调用 API 的密钥。调用方只需要支持 HTTPS 和标准 JSON 请求即可。

<Steps>
  <Step title="登录控制台">
    打开 [aibal.ai 控制台](https://aibal.ai)，进入 **渠道** 页面确认目标模型处于可用状态。
  </Step>
  <Step title="创建 API 密钥">
    进入 **API 密钥**，创建一个描述清晰的密钥。为密钥设置有效期和可访问分组，并在离开页面前安全保存完整值。
  </Step>
  <Step title="配置客户端">
    将密钥放入服务端环境变量，并把 SDK 的 `base_url` 指向平台提供的 API 地址。

    ```bash
    export AIBAL_API_KEY="sk-your-key"
    export AIBAL_BASE_URL="https://api.aibal.ai/v1"
    ```
  </Step>
  <Step title="发起请求">
    使用兼容 OpenAI 的客户端发送第一条消息。将 `model` 替换为控制台中已启用的模型。

    ```bash
    curl "$AIBAL_BASE_URL/chat/completions" \
      -H "Authorization: Bearer $AIBAL_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "your-model",
        "messages": [{"role": "user", "content": "你好，请介绍一下你自己。"}]
      }'
    ```
  </Step>
</Steps>

## 首次调用失败时

- `401`：检查密钥是否完整、是否已撤销，以及 `Authorization` 格式。
- `403`：确认密钥所属分组有权访问该模型。
- `429`：检查并发限制、余额和渠道速率限制。
- `5xx`：在控制台查看请求日志，确认上游渠道状态后重试。
