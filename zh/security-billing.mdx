## 核对调用与费用

打开控制台的[使用记录](https://aibal.ai/usage)，按时间、模型和 Key 核对调用与消耗。发现异常时，先停用相关 Key，保留请求 ID、任务 ID 和脱敏错误信息，再联系支持。网络超时不等于未产生任务或费用，不要盲目重复提交。

<Note>
不要公开密码、验证码、API Key 或完整支付信息。密钥泄露时停用旧 Key 并创建新 Key；分享日志和截图前先脱敏。
</Note>
