## API 密钥管理

为每个环境或服务创建独立密钥，使用有意义的名称和过期时间。发现泄露时立即撤销并重新生成，不要尝试通过修改前端代码隐藏密钥。

## 计费与余额

费用通常与模型、输入输出 Token、图片或其他媒体计量方式有关。控制台中的用量记录用于核对请求；实际价格、折扣和最低充值规则以账户当前页面和服务条款为准。建议为生产分组设置预算告警。

## 最小权限

密钥只授予必要的模型和分组权限。团队成员使用个人账户，服务使用专用密钥；定期清理长期未使用的密钥和渠道。

## 数据保护

不要在提示词中发送不必要的个人敏感信息、密码、私钥或完整支付数据。根据业务合规要求设置日志保留策略，并在应用侧对用户输入和模型输出做脱敏与审计。

<Tip>遇到账单异常时，先冻结相关密钥，再按时间、模型、分组和请求 ID 核对日志。这样可以在不扩大影响范围的情况下保留排查证据。</Tip>
