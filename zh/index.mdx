# 一站式 AI 接入平台

aibal.ai 为应用开发者提供统一的 AI API 入口。你可以在一个控制台中配置多个上游模型服务，创建项目密钥，按团队或业务分组管理访问权限，并通过兼容 OpenAI 的接口快速接入现有应用。

## 你可以用 aibal.ai 做什么

- 通过统一接口调用聊天、文本生成、视觉和嵌入模型。
- 将不同供应商隐藏在同一层路由之后，减少应用侧改造成本。
- 为开发、测试和生产环境创建独立密钥。
- 查看请求量、Token 用量、余额和费用明细。
- 使用分组、限额和权限策略隔离团队与业务。

## 推荐接入流程

1. 注册并登录控制台。
2. 配置可用的上游渠道和模型。
3. 创建一个仅用于当前环境的 API 密钥。
4. 将应用的 `base_url` 指向 aibal.ai API 地址。
5. 在控制台检查调用日志、用量和错误信息。

<Note>请把 API 密钥当作密码保存。生产环境建议使用服务端代理和密钥管理系统。</Note>
