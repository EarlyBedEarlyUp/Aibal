你可以在 aibal.ai 网页端创作，也可以把账户中的 API 服务接入本地编程工具。先选定工具，再按对应教程配置。

## 选择使用方式

| 你的目标 | 推荐入口 | 需要准备 |
| --- | --- | --- |
| 不安装软件，先体验图片或视频生成 | [网页端快速体验](/zh/web-quickstart) | 已登录账户、API Key 及可用余额 |
| 通过图形界面管理、切换多个编程工具的服务 | [cc-switch](/zh/cc-switch) | CC Switch、目标客户端、API Key |
| 在终端中使用 Codex 编程 | [Codex](/zh/codex) | Codex CLI、支持 Responses 的模型与 API Key |
| 在终端中使用 Claude Code 编程 | [Claude Code](/zh/claude-code) | Claude Code、可用 Claude 模型与 API Key |
| 在自己的程序中生成图片或视频 | [文生图](/zh/text-to-image) / [文生视频](/zh/text-to-video) | 程序运行环境及对应服务权限 |

## 操作前准备

<Steps>
  <Step title="准备账户">
    先[注册账户](/zh/register)，登录 [aibal.ai](https://aibal.ai/)，确认账户可以正常使用。需要补充余额时，按[充值指南](/zh/recharge)操作。
  </Step>
  <Step title="为工具创建 API Key">
    按[创建 API Key](/zh/create-api-key)创建专用密钥，例如分别命名为 `codex-laptop` 和 `claude-work`。确认密钥已启用、未过期，分组支持你要使用的模型。
  </Step>
  <Step title="查看当前密钥的使用配置">
    在密钥列表中点击 **使用密钥**，选择对应客户端和操作系统。优先参考这里生成的地址与模型配置；不同分组的配置可能不同。不要用账户登录密码代替 API Key。
  </Step>
  <Step title="配置并验证">
    打开对应工具教程，保存配置后启动一个新会话。先发送一条简短文本，成功后在控制台 **使用记录** 中核对模型和消耗，再开始正式任务。
  </Step>
</Steps>

<Note>
测试消息也会产生模型调用，费用、支持模型和额度以控制台当前展示为准。能在网页端生成图片，不代表同一密钥自动拥有所有文本或视频模型的权限。
</Note>

## 地址、密钥和模型怎么填

| 字段 | 填写内容 | 常见错误 |
| --- | --- | --- |
| Codex / OpenAI 兼容 Base URL | `https://aibal.ai/v1` | 填成网站登录地址，或重复添加 `/v1` |
| Claude Code `ANTHROPIC_BASE_URL` | `https://aibal.ai` | 手动追加 `/v1/messages`；客户端会组合请求路径 |
| API Key | 当前账户创建且有对应分组权限的密钥 | 使用密码、验证码或其他平台密钥 |
| 模型 | 当前密钥使用配置中支持的完整模型 ID | 使用展示昵称，或照抄其他平台的模型名称 |
| 协议 | Codex 用 `responses`；Claude Code 用其 Anthropic 兼容配置 | 只改模型名称而不检查接口兼容性 |

以上是常用入口。如果 **使用密钥** 给出了带有其他路径的专用地址，请保留完整地址并使用该分组的配置，不自行删改。

## 如何判断接入成功

客户端能正常返回回答，且控制台 **使用记录** 出现对应时间、密钥和模型的调用记录，才说明这次请求走到了你的 aibal.ai 账户。仅看到“配置已保存”或客户端成功启动，还不能说明模型调用成功。

## 常见问题

### 返回 401 或密钥无效

重新复制完整密钥，检查前后空格、环境变量是否在当前终端生效，以及密钥是否已删除或禁用。不要把真实密钥发到群聊或公开工单。

### 返回模型不可用或权限错误

检查密钥分组、完整模型 ID 和客户端协议。切换到该密钥使用教程中的可用模型；仍失败时，提供错误文本、时间和客户端版本给支持人员。

### 返回 404、429 或余额不足

`404` 先检查地址是否重复拼接 `/v1`；`429` 查看并发或速率限制，降低请求频率后再试。余额或额度不足时，检查账户余额、订阅状态和密钥额度，按提示处理。

### 需要提供哪些排查信息

提供客户端名称与版本、发生时间、模型 ID、脱敏后的 Base URL 和错误文本。截图必须遮住密钥、邮箱和账户信息。密钥泄露时立即停用并重新创建。
