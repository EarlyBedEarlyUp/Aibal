## 通用配置

大多数客户端只需要三项信息：

```text
服务地址：https://aibal.ai/v1
API Key：你在控制台创建的密钥
模型：控制台当前开放的模型标识
```

如果客户端把服务地址和路径分开填写，服务地址填写 `https://aibal.ai`，接口路径保留客户端默认的 `/v1`。

## cc-switch

在 cc-switch 中新增一个自定义服务配置，填写 aibal.ai 的服务地址和 API Key，选择与控制台一致的模型。保存后先发送一条短消息，确认返回、延迟和余额扣减均正常，再切换日常工作流。

## Codex

在 Codex 的 provider 或环境配置中使用 aibal.ai 的兼容 API 地址和 API Key。建议为 Codex 单独创建密钥，并限制到需要的服务分组。遇到模型不可用时，先复制控制台中的模型标识，不要凭记忆改写名称。

## Claude Code

在 Claude Code 的环境变量或 provider 配置中填写 aibal.ai 的服务地址和 API Key。使用前确认账户已开通对应的服务分组；如果返回权限、模型或余额错误，先在控制台检查 Key 状态和剩余额度。

## 网页端快速尝试

不想配置客户端时，直接登录 aibal.ai，在在线文生图或文生视频页面提交一次最小任务。网页端适合验证账户、模型、费用和结果链路；验证成功后再复制 API Key 到本地工具。

<Tip>
所有客户端都应从环境变量或密码管理器读取 API Key。不要把真实密钥放到截图、公开教程或前端代码中。
</Tip>
