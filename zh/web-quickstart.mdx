你可以直接在 aibal.ai 网页端体验图片和视频生成。首次建议先生成一张图片，完成从准备账户、选择 Key 到保存结果的完整流程。

## 操作前准备

使用能访问 [aibal.ai](https://aibal.ai/) 的现代浏览器。你需要已登录的账户、可用余额或额度，以及能调用相应模型的 API Key。网页体验也会产生调用费用，不代表免费试用。

## 完成第一次体验

<Frame caption="首次进入在线生图的页面（中文界面；没有可用 API Key 时需先创建）">
  <img src="/images/text-to-image-zh.png" alt="首次体验的在线生图入口，显示 API Key 准备提示和图片生成区域" />

<Steps>
  <Step title="注册并登录">
    已有账户时直接[登录](https://aibal.ai/login)；新用户先按[注册账户](/zh/register)完成注册，再进入控制台。
  </Step>
  <Step title="确认余额">
    在控制台检查可用余额，需要时按[充值账户](/zh/recharge)通过 USDT 或兑换码充值。具体可用方式和到账结果以页面为准。
  </Step>
  <Step title="准备 API Key">
    按[创建 API Key](/zh/create-api-key)创建一个便于识别的 Key，并选择支持图片生成的分组。只需在网页选择这个 Key，无需把它粘贴到提示词里。
  </Step>
  <Step title="打开在线生图">
    进入[在线生图](https://aibal.ai/image-studio)，选择 **API Key**。保留自动尺寸、自动质量、1 张和 PNG 格式，不添加参考图。
  </Step>
  <Step title="输入提示词并生成">
    输入“一只橙色小猫坐在窗边，水彩插画风格，无文字”，点击 **生成**。保持页面打开，等待结果。
  </Step>
  <Step title="保存图片并查看使用记录">
    在成功的结果卡片上点击 **预览** 和 **下载**。打开[使用记录](https://aibal.ai/usage)核对这次调用；刷新或离开生图页面前先保存图片。
  </Step>
</Steps>

你现在应已获得一张保存在本地的图片。希望调整主体、风格或参考图时，继续阅读[文生图（在线使用与 API）](/zh/text-to-image)。

## 常见问题

### 为什么网页生成也需要 API Key

网页工作台会使用你选择的 Key 提交调用。它的启用状态、分组、额度和模型权限都会影响结果，登录状态不能替代这些条件。

### 为什么有余额还是不能生成

检查 Key 是否启用、是否达到额度、所属分组是否支持目标模型。按页面的具体错误提示处理；不要只反复点击生成。

### 可以关掉页面再回来吗

图片结果列表属于当前页面会话，请先下载。已提交的视频可在 **历史任务** 查看；关闭页面不会取消生成。如果网络中断或状态不明确，先核对任务与使用记录，再决定是否重试。

### 手机可以使用吗

你可以用手机浏览器访问同一入口。参数区域收起时，点击 **生成设置** 或 **视频参数** 展开；下载和保存方式以手机浏览器为准。

<Warning>
不要在提示词中填写密码或 API Key。分享页面截图前，检查 Key 选择框、调用示例、账户资料和结果内容，避免泄露敏感信息。
</Warning>
