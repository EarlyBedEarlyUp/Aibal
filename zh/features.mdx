## 统一模型路由

aibal.ai 在应用与上游供应商之间提供统一路由层。应用只需使用平台规定的模型名称和接口格式，即可在控制台调整渠道、优先级和故障转移策略。

## 渠道与模型

渠道代表一个可用的上游凭据或供应商连接。你可以为不同环境配置不同渠道，并控制哪些模型对外开放。修改渠道配置后，建议使用测试密钥验证响应、延迟和错误率。

## 分组与限额

分组用于隔离项目、团队和租户。每个分组可以拥有独立的密钥、模型白名单、并发限制、每日或每月预算。将密钥绑定到最小权限分组，可以降低误用和费用失控风险。

## 用量与日志

平台记录请求时间、模型、状态码、Token 和费用等信息。排查问题时，使用请求 ID 在日志中定位完整链路；分析费用时，按密钥、分组和模型筛选时间范围。

## 兼容性

平台优先兼容 OpenAI 风格的 Chat Completions 请求。大多数现有 SDK 只需修改 API 地址和密钥即可接入。不同上游对流式输出、工具调用、视觉输入和 JSON 模式的支持可能不同，请以实际模型能力为准。

<Warning>不要在前端 JavaScript、移动端安装包或公开代码仓库中嵌入长期 API 密钥。</Warning>
